본문은 목차의 자동 번호 매기기 기능을 끄는 방법을 보여줍니다.

## 목차 번호 매기기 기능

기본적으로 astro-koharu는 CSS 카운터를 사용하여 다음과 같이 목차에 계층 번호를 자동으로 추가합니다:

- 1. 제1장
  - 1.1. 제1절
  - 1.2. 제2절
- 2. 제2장

## 번호 매기기 비활성화

`tocNumbering: false`를 설정하여 특정 게시물의 번호 매기기를 끌 수 있습니다:

```yaml
---
title: 나의 게시물
tocNumbering: false
---
```

## 효과 비교

### 번호 매기기 활성화 (기본값)

목차 항목에 1., 1.1., 1.1.1.과 같은 번호가 표시됩니다.

### 번호 매기기 비활성화

목차 항목에 번호 접두사 없이 제목 텍스트만 표시됩니다.

## 본문 적용 효과

이 게시물은 `tocNumbering: false`로 설정되어 있습니다. 오른쪽 목차(데스크톱)를 확인하거나 목차를 펼쳐서(모바일) 효과를 확인할 수 있습니다.

## 기술적 구현

번호 매기기 기능은 순수 CSS 카운터를 통해 구현되어 런타임 오버헤드가 전혀 없습니다:

```css
.toc-numbering {
  counter-reset: h2;
}

.toc-numbering h2::before {
  counter-increment: h2;
  content: counter(h2) ". ";
}
```

## 사용 권장 사항

다음과 같은 상황에서는 번호 매기기를 비활성화하는 것이 좋습니다:

- 에세이 형식의 글
- 제목 자체에 이미 번호가 포함된 경우
- 내용 구조가 느슨한 글
- 개인적인 취향

## 요약

목차 번호 매기기는 선택 사항이므로, 게시물의 유형에 따라 유연하게 사용하면 됩니다.
