주간지/시리즈 기사 기능의 사용법을 보여주는 예시 주간지입니다.

## 주간지 기능에 대하여

주간지는 astro-koharu의 특징적인 기능 중 하나로, 다음과 같이 정기적으로 업데이트되는 시리즈 콘텐츠를 게시하기에 적합합니다:

- 기술 주간지
- 독서 노트 시리즈
- 학습 기록
- 프로젝트 진행 상황 업데이트

## 주간지 설정

`config/site.yaml`에서 설정합니다:

```yaml
featuredSeries:
  categoryName: 주간지       # 카테고리 이름
  label: 나의 주간지          # 표시 라벨
  fullName: 나의 기술 주간지
  description: 주간지 설명...
  cover: /img/weekly_header.webp
  enabled: true            # false로 설정 시 비활성화
```

## 주간지 특징

1. **전용 페이지** - 주간지는 독립된 `/weekly` 페이지를 가집니다.
2. **홈페이지 노출** - 최신호가 홈페이지 상단에 고정되어 표시됩니다.
3. **독립된 목록** - 주간지는 일반 게시물 목록에 나타나지 않습니다.
4. **시리즈 내비게이션** - 주간지 간에 이전/다음 글 내비게이션이 제공됩니다.
